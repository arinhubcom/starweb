# Update Starweb

The steps change with each Starweb version, and the copies in this project are older than the new version. So take them from the Starweb clone, not from this project.

1. Find the Starweb clone, for example `~/starweb`. If there is no clone, clone `https://github.com/arinhubcom/starweb`.
2. Run `git pull` in the clone.
3. Read `rules/UPDATE.md` in the clone, and do the steps in "Starweb update" in order.
4. If a step fails, stop and report the error.
